# 发布记录

## 3.0.4 — 2026-10-14（正式发布，仅安装版）

- 处理“按钮可点击，但所有输入框无法聚焦”的可疑触发路径：删除、放弃草稿、替换名单等不再使用阻塞的浏览器原生确认框，改为应用内异步确认。原问题重启后已消失，未宣称复现了用户当时的确切操作。
- 确认默认聚焦取消，Escape 取消；关闭后恢复可见控件焦点，确认仍是删除、替换和清空的前提。
- 桌面退出的未保存提醒改为异步：继续编辑恢复窗口与页面焦点，放弃退出仍需确认；重复关闭不会叠加提醒。增加“视图 → 恢复输入焦点”（Ctrl+Shift+F6），不刷新工作区、不清除草稿。
- 包含此前本机 3.0.3 的图形化座次工作台、锁定与撤销、会议室桌型自动带入；输入焦点修复于 2026-10-08 完成，本次统一发布。
- 从本次正式发布起只构建、测试和分发 NSIS 安装程序；不再生成便携版。历史 Release、标签和旧便携数据保留，不重写历史、不自动迁移用户数据。
- 三处版本统一为 `3.0.4`，源码提交、`v3.0.4` 标签与 Release 对应同一版本。安装程序及 SHA-256 校验文件放在 Release，不将 EXE 提交源码仓库。在线与下载版手册同步为 3.0.4。
- ESLint、生产构建和 235 项自动测试通过，包含“只构建安装版”的回归约束。独立数据下安装版所用解包 EXE 两次启动，验证三次取消、Escape、确认后的输入框/文本框键盘输入，以及会议、通讯录、模型配置和会议室桌型重启保留；退出确认的取消/放弃/重复关闭/异常路径使用单元测试验证，未在用户窗口实际关闭或覆盖安装。界面验证默认取消、Tab 焦点循环、原控件焦点恢复和移动端边界。
- 额外运行 `tsc --noEmit` 仍提示原有名单文件类型、助手测试及 worker 平台声明等问题；相关报错位置未被本次焦点修复改写。本次不宣称全量类型检查通过，也未将这些独立问题混入修复。

## 3.0.3 — 2026-10-08（本机重新打包）

- 座次改为图形化工作台，支持图上换座、锁定、撤销/重做、缩放和人员定位；保存独立方案，不自动开启正式名单治理。
- 会议室新增可选桌型：长方桌、圆桌 / 宴会式、主席台 / 排座、未配置。首次编排和切换参考会议室自动带入对应通用模板，仍允许单次手动调整。
- 已保存的模板、人工调整和锁定优先保留；会议室配置变化不覆盖旧方案，不推算桌型或容量。旧房间没有桌型字段仍可读取、保存和回滚。
- 三处应用版本统一为 `3.0.3`，重新生成安装版和便携版，操作手册同步更新。GitHub 已发布 `3.0.2` 保持不变，本次不自动上传发布。
- 代码检查、生产构建和 225 项自动测试通过。独立演示数据验证桌型配置保存、延迟加载、首次带入、临时改选及已保存/锁定方案保护；安装版所用解包程序与单文件便携版分别两次启动，确认会议、通讯录、浏览器配置及会议室桌型重启保留。未在本机覆盖安装实际用户软件。

## 发布验证

```bash
npm run lint
npm test
npm run desktop:build
node scripts/test-desktop.mjs
```

测试数据使用独立临时目录，不修改用户业务数据。发布产物仅为 Windows x64 安装程序；解包运行程序用于自动验证，不作为免安装下载提供。EXE 未配置签名证书，不宣称已数字签名。

GitHub 下载名为 `MeetingAssistant-3.0.4-Setup.exe`，本地打包为 `会务智办-3.0.4-安装版.exe`，二者内容和 SHA-256 相同。Release 同时提供 `SHA256SUMS-3.0.4.txt`，不上传便携 EXE，不将安装程序提交进源码历史。

每次正式发版先审查改动与敏感文件，完成测试并构建；提交源码后创建新的 `v版本号` 标签，推送主分支及标签；以标签创建 Release 草稿，上传安装程序和校验文件，核对资产与提交后再发布。已发布标签和安装包不覆盖，后续修改使用新版本号。主分支可以有未发布更新，下载页以 Release 为准；旧的本机 3.0.3 没有独立正式发布标签，不补造历史。
