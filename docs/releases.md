# 发布记录

## 3.1.5 — 2026-10-27（正式发布，仅安装版）

- 新增 Windows 安装版软件内更新：启动约 10 秒后检查公开 GitHub 最新正式版，运行期间每 6 小时检查一次；菜单“会务智办 → 软件更新”可手动检查。
- 更新窗口展示当前/最新版本及说明，支持下载进度、取消、重试和打开发布页。关闭窗口可继续下载，下载完成显示“退出并安装”。网络不可用或没有新版时，后台检查不打断工作。
- 校验安装包大小和 GitHub SHA-256，拒绝其他仓库地址、非安装版、缺少校验、草稿、预发布及版本降级。取消或失败不留下可执行半包；安装请求及实际交接前重验。
- 安装走现有未保存内容确认；取消退出或确认失败立即取消安装请求，不会在后续普通退出时意外安装。主窗口和后台关闭后，更新当前目录并重新启动，保留业务数据及配置。
- 更新界面与业务网页隔离，不给业务网页进程控制权限。GitHub 仓库已公开，无需账号、令牌或代理服务；3.1.4 及更早版本须先手动安装本版一次。源码网页版及旧便携版不执行自动安装。
- 新增 `npm run release:prepare` 生成更新器使用的英文安装包名与 SHA-256 文件；发布时必须使用对应新 tag、正式 Release 并设为 Latest，历史发布不覆盖。
- 匿名 GitHub API 限流时，使用公开发布页与同版校验文件继续检查和下载，无需用户填写令牌。
- 发布核验：ESLint、完整类型检查、生产构建与 276 项自动测试通过；安装版所用解包 EXE 两次启动通过，实际加载沙箱更新窗口并完成虚构新版检测、下载与校验，验证会议、通讯录、浏览器配置与会议室桌型重启保留。独立缓存已实际下载公开 3.1.4 安装包并核对 SHA-256，覆盖真实 API 限流备用路径。安装交接参数、篡改拒绝及未保存确认取消/异常由自动测试验证，未在用户实际安装目录执行覆盖安装；未执行真实模型调用。
- 同步在线、Word/PDF 手册和独立测试更新窗口截图；源码、三处版本、`v3.1.5` 与 Release 对应同一版本。

## 3.1.4 — 2026-10-27（正式发布，仅安装版）

- 新增 `npm run typecheck`，自动测试和桌面打包先检查类型，防止再次带着类型报错打包。
- 桌面验证区分 Windows 组件加载失败（`0xC0000135`）与渲染沙箱受限令牌创建失败（`49`），附日志路径；继续保留原有沙箱及全部验证断言。
- 包含 3.1.0 至 3.1.3 的会议方案、助手页面联动、聊天历史与白屏修复、AI 写入后页面自动更新及人工草稿保护。
- 修正桌面验证脚本对助手入口的假设：重启后助手恢复打开时，直接验证会话，不再点击已隐藏的启动按钮。未改变产品的会话恢复行为。
- 发布核验：ESLint、完整类型检查、生产构建和 266 项自动测试通过。重新构建 Windows x64 NSIS 安装包；在正常 Windows 执行环境、独立虚构数据下，两次启动均通过，包含连续会议草稿、会话刷新恢复、输入焦点恢复，以及会议、联系人、浏览器配置、会议室和桌型重启保留。受限账户的组件加载失败不作为本轮功能验收结果；未关闭渲染沙箱或加入软件渲染参数。真实模型调用及 Word/WPS 实际分页未在本轮验证。
- 源码、`v3.1.4` 标签与 Release 对应同一版本；Release 提供 `MeetingAssistant-3.1.4-Setup.exe` 和 `SHA256SUMS-3.1.4.txt`，同步在线及 Word/PDF 手册。3.1.0 的旧 GitHub 草稿和已发布历史保持原状。

## 3.0.4 — 2026-10-14（正式发布，仅安装版）

- 处理“按钮可点击，但所有输入框无法聚焦”的可疑触发路径：删除、放弃草稿、替换名单等不再使用阻塞的浏览器原生确认框，改为应用内异步确认。原问题重启后已消失，未宣称复现了用户当时的确切操作。

- 包含此前本机 3.0.3 的图形化座次工作台、锁定与撤销、会议室桌型自动带入；输入焦点修复于 2026-10-08 完成，本次统一发布。

## 发布验证

```bash
npm run lint
npm run typecheck
npm test
npm run desktop:build
node scripts/test-desktop.mjs
npm run release:prepare
```

测试数据使用独立临时目录，不修改用户业务数据。发布产物仅为 Windows x64 安装程序；解包运行程序用于自动验证，不作为免安装下载提供。EXE 未配置签名证书，不宣称已数字签名。

已发布 3.0.4 的 GitHub 下载名为 `MeetingAssistant-3.0.4-Setup.exe`，本地打包为 `会务智办-3.0.4-安装版.exe`，二者内容和 SHA-256 相同。Release 同时提供 `SHA256SUMS-3.0.4.txt`，不上传便携 EXE，不将安装程序提交进源码历史。

每次正式发版先审查改动与敏感文件，完成测试并构建；提交源码后创建新的 `v版本号` 标签，推送主分支及标签；以标签创建 Release 草稿，上传安装程序和校验文件，核对资产与提交后再发布。已发布标签和安装包不覆盖，后续修改使用新版本号。主分支可以有未发布更新，下载页以 Release 为准；旧的本机 3.0.3 没有独立正式发布标签，不补造历史。
