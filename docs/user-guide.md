# 使用指南

[返回仓库首页](../README.md) · [图文操作手册](operation-manual.md) · [开发与构建](development.md)

适用于本机 `3.0.4`。GitHub 下载仍以发布页实际版本为准；本指南介绍业务功能、配置和数据边界。

第一次使用建议阅读[带截图的操作手册](operation-manual.md)，按按钮操作；可下载[Word 版](downloads/会务智办操作手册.docx)或[PDF 版](downloads/会务智办操作手册.pdf)。本指南保留详细规则和功能边界，不重复图文步骤。

## 功能概览

本机单用户会务工作台。功能按业务边界拆开，但共享会议、人员和规则数据：

- **会议项目**：按场景生成会前、会中、会后核对事项，管理负责人、截止日期、风险和操作指引。
- **会务待办**：按所属会议汇总逾期、今日、近期、阻塞和已完成事项，集中分配负责人、补充临时事项并更新状态。
- **名单治理**：识别杂乱名单，统一单位名称，按单位层级和职务层级排序并导出 Excel。
- **人员通讯录**：自动沉淀历史参会人，支持模糊搜索和姓名、单位、部门、职务回填。
- **座次编排**：在会议详情独立编排主席台、长方桌或圆桌座次，支持导入名单、职级/权重核对、主客方识别、图示、人工交换及 Excel 导出。
- **会务智能助手**：连续理解自然语言和上下文，直接交付文字成果，并联动会议、清单、参会人、通讯录和名单工具。
- **资料辅助填报**：在助手点击“添加资料”，支持 Word（.docx）、Excel、PDF/OCR、图片和文本；点击“识别并填入会议草稿”后，核对会议信息、议程与参会人员，再确认创建。可继续用自然语言修正同一份草稿，不会自动开启正式名单治理。
- **管理中心**：在网页中维护公司默认值、会议规则、清单模板、单位字典、名单层级和 Excel 输出格式，无需为日常口径调整重写代码。

## 资料识别与填报

助手资料仅在本次会话内存中保留，刷新后丢失。每次最多 5 份、每份 20 MB / 24,000 字、合计 60,000 字；超限明确提示拆分，不静默截断。PDF 最多 60 页、扫描页最多 30 页。OCR 首次运行需要下载识别资源；识别后的文字会发送给所选模型，使用前应确认资料允许出网。文件原件不保存到会议，确认后保存结构化字段、议程备注和人员。这里的“上报”是录入本系统，不包含提交公司 OA 或外部审批。

## 管理中心

打开主导航的“管理中心”，可以配置：

1. 组织名称、默认负责人、开始时间、参会人数、会议规模和投屏默认值。
2. 停车车辆上限、商务餐参考标准、大型会议加水间隔及五类风险提醒。
3. 会议清单模板的新增、复制、删除、启停、排序、阶段、分组、生成条件和截止日期。
4. 单位简称/全称字典，并选择“自动合并”或“人工确认”。
5. 国家/省/市/区县等单位层级、职务层级、指定单位优先级，以及兼容的拼音排序模式。
6. Excel 字段、表头、列宽、工作表、筛选、冻结首行和文件名。
7. 公司专用的 AI 提取补充要求。
8. 独立人员通讯录的新增、修改、删除、搜索和历史会议补录；通讯录修改即时生效。
9. 配置发布、JSON 导入导出和历史版本回滚。

公司规则、会议室、清单模板、单位字典、名单导出各有就近的独立保存按钮，只保存当前页修改；“配置总览 / 数据维护”可保存全部草稿。管理中心使用单一整页滚动，左侧菜单停靠，不设置左右两列内部滚动条。

安装版内置置地中心 10–12F 的 6 间会议室（未提供 24F 房间，暂不新增），保留所报面积和会议桌尺寸。首次运行将随程序发布的默认配置原子写入本机数据目录；升级旧版本时只补入缺少的房间，以 ID 或同名判断已有房间，不覆盖其名称、人数、启停和其他配置。初始化有版本标记，之后的修改、停用、删除及历史回滚不会被重新安装/重启自动重置；卸载保留业务数据。容纳人数没有提供，默认 0（未登记），不从面积推算，也不自动选择某一间作为默认会议室。面积和尺寸可在“管理中心 → 会议室管理”独立编辑，选中会议室后作为本次会议的场地信息快照保留。

构建时 `dist/default-admin-config.json` 仅由代码中的内置默认配置生成并随运行文件一起分发，不读取用户本机会议、通讯录、模型配置或 API Key。

每间会议室可独立配置“会议桌型”：长方桌、圆桌 / 宴会式、主席台 / 排座，或未配置。修改后点击本页“保存会议室”。桌型用于座次模板自动选择，不从桌子尺寸猜测，也不自动登记容量；内置及旧会议室默认未配置，需按现场情况维护。

会议默认值、清单和提醒在创建会议时形成快照，之后修改配置不会覆盖已有会议任务。单位字典、排序和 Excel 规则属于名单工具的运行口径，从下一次名单整理或导出开始使用。

配置保存在：

```text
%LOCALAPPDATA%\MeetingAssistantAI\admin-config.json
```

系统使用原子写入、备份恢复、版本冲突检查和按文件大小裁剪的历史记录；API Key 不进入管理配置、备份或历史版本。

人员通讯录独立保存在同目录下的 `contacts.json`，不会混入带版本回滚的管理配置。

通讯录按“姓名＋单位字典标准全称”去重，创建、修改、历史会议同步和旧快照恢复使用同一规则。已配置且启用的精确简称可归一，不按模糊名称猜测同一单位；同名但不同单位保持独立。旧数据中的简称/全称重复记录会在读取时合并并原子保存，保留人工编辑记录的 ID、人工字段和去重的参会历史；合并前的数据进入通讯录备份。未知简称需先维护单位字典。

## 会议项目

- 内置来源于《会议全流程核对清单》的 29 项标准动作和 4 张金蝶人人费用操作指引。
- 可按下午会议、用餐、停车、宣传、报销、PPT、欢迎屏和会议室规模生成适用任务。
- 支持直接编辑、复制、归档、恢复和回收站；删除先进入回收站，只有再次确认才会彻底删除。
- 会议室从管理中心统一选择；同一会议室在相同日期、重叠时段被重复安排时，系统会在保存前阻止并指出冲突会议。
- 会议列表支持按名称、地点、负责人和组织单位搜索，可按待举行、未来 7 天、本月和已结束筛选，并可在卡片与日程视图之间切换。
- 每项任务支持状态、负责人、截止日期、备注和留痕文件名。
- “会务待办”按会议展示日期、地点、会议负责人和真实进度，可按负责人、阶段和关键字筛选，直接完成、恢复或新增临时事项。
- 某场会议或某个阶段没有适用事项时按 100% 计算，并明确显示“无需额外操作”，不再出现无法完成的 0%。
- 自动统计进度，并按管理中心规则提示地点、负责人、名单、车辆、逾期和阻塞风险。
- 参会名单可以从“名单治理”回写当前会议。

## 会议座次编排

打开会议详情的“座次编排”：使用会议人员、手动添加（支持通讯录搜索），或导入 Excel/CSV、Word 表格、文本名单。粘贴名单建议使用 Markdown 表格或制表符分列，列名为“姓名、单位、职务、职级、所属方”，可附“权重”和“角色（主持人）”。

座次工作台左侧人员列表支持搜索与分页，中间是可交互座次图，右侧显示选中人员、席位详情和排座规则。首次编排自动读取会议已选会议室的桌型，切换“编排参考会议室”也会带入对应模板：长方桌对应普通长方桌会谈，圆桌对应圆桌，主席台 / 排座对应主席台自动单/双中心；不会自动选择 5 对 5。未配置桌型时保留当前布局。可按本次会议手动改选单中心、双中心、宽间距、5 对 5 等模板，不影响会议室默认桌型。参考会议室显示已有面积、桌子尺寸、桌型及登记容量，不改会议本身的预订场地，不根据面积猜容量，也不生成实测平面图。

已保存的座次方案优先使用原模板，后台桌型变化不会自动覆盖它。主动切换参考会议室后，旧图和锁定保留并提示重新生成；若新布局与锁定不兼容，须先解除锁定。助手在没有已保存方案且用户未指定会议形式时也按会议室桌型选择，写入仍须人工确认。

点击座位后选择“交换席位”，再点击另一席；桌面上也可直接拖动两席交换，触屏和键盘可用按钮完成。关键席位可锁定，锁定同时保护人员及物理位置，保存后重新打开仍保留；手动与助手重新生成均保留兼容布局中的锁定，模板、入口、每排人数或中心布局变化不兼容时必须先解锁。空席是模板预留位置，不支持随意拖入人员。图形工具栏支持放大、缩小和适应窗口，默认优先保证姓名可读，选择人员会自动定位其席位。“分组表格”是辅助视图。

修改人员或规则不会清空上次图示，但会显示“待重新生成”，重新生成前不能换座、保存或导出。撤销/重做保存本页最近 60 步操作，只在当前页面会话内有效，不等同于跨版本恢复。输入框中的未读取名单须先读取或清空。生成或调整后点击顶部“保存座次”，导出 Excel 的“依据与提醒”页包含锁定席位说明。关闭脏页签仍使用工作区统一确认。

默认 2 号位于就座者左手侧（单排图上 1 号右侧）；长方桌双方按各自朝向镜像排列。门位和本方主位/全体职级优先规则可选；偶数人数且头两位权重接近时自动采用双中心。主席台示意前排靠近下方会场，箭头标明就座朝向。

这是按用户提供规则生成的礼宾建议，不等同于经过核验的官方标准。默认职级/公司职务权重只是辅助，可逐人填写人工权重；不明职级提示人工核对。主方中心与全体职级冲突、人工调整导致朝向变化等均显示提醒。座次方案独立保存，不覆盖原参会人员，也不自动启用正式名单治理。助手可生成座次操作预览，确认后写入；无须调用模型即可手动编排。

单次 1–200 人，主席台每排最多 30 人，长方桌每侧最多 30 人，圆桌最多 30 人。座次图是方向示意，不是按会议室真实尺寸建模；实际空间、席位礼序应由会务人员最终确认。

## 名单治理

- 支持 Excel（`.xlsx`、`.xls`、`.csv`）、Word（`.docx`）、PDF、图片、文本文件和直接粘贴。
- PDF 优先提取原生文字；扫描页和图片使用中英文 OCR，单个 PDF 最多 60 页，其中扫描 OCR 最多 30 页。
- 支持 DeepSeek、OpenAI、Kimi、豆包和自定义 OpenAI 兼容接口。
- AI 负责理解不规范文本；程序负责去重、归并、可解释排序、编号和 Excel 生成。
- 姓名、单位、部门、职务和来源均可人工核对。
- 默认先按单位层级，再按同单位内的职务层级；旧配置自动迁移为拼音兼容模式，避免历史顺序突变。
- “AI 分析排序”可给出本次名单的单位层级建议，必须人工勾选确认后才参与排序。
- 姓名旁可从通讯录模糊搜索回填；职务旁可联网检索公开来源并展示候选，用户确认后才带入。
- 导出字段、顺序、表头、列宽、工作表、文件名、筛选和冻结首行均可在管理中心调整。
- 单次合计上限为 100,000 字；单个工作表最多 5,000 行。超过时系统明确阻止并提示拆分，不会静默截断人员。

## Windows 本地运行

### 桌面 EXE

运行 `npm run desktop:build` 仅生成 Windows x64 安装程序，输出位于 `release/desktop/`。从 3.0.4 正式发布起不再提供便携版；使用桌面软件须先安装。软件内置 Electron 与 Node.js 运行环境，使用者无需另装 Node.js。

- 安装版：运行“会务智办-3.0.4-安装版.exe”，选择安装目录后从桌面快捷方式打开。业务数据沿用 `%LOCALAPPDATA%\MeetingAssistantAI`，升级和卸载均保留业务数据。
- GitHub `3.0.4` 安装程序使用英文文件名 `MeetingAssistant-3.0.4-Setup.exe`；下载时核对发布页版本与 SHA-256 校验文件。已发布安装程序不会随主分支修改自动变化。
- 桌面版首次使用需要重新填写模型 API Key；原浏览器中的 Key 不会自动复制。AI 功能仍然需要联网和模型调用额度。
- 安装版会读取已有默认网页版业务数据。历史便携版的数据仍在旧 EXE 旁“会务智办数据”目录，不会自动迁移或合并到安装版；迁移前备份两个目录并核对内容，不直接覆盖已有业务数据。窗口菜单可以打开数据与日志文件夹。
- 桌面后台使用固定本机地址 `127.0.0.1:32187`，可以与源码网页版的 3000 端口共存。升级前退出旧桌面程序。
- 业务确认使用软件内窗口，默认聚焦“取消”；按 Escape 取消，不删除或覆盖数据。关闭软件存在未保存内容时仍需选择“继续编辑”或“放弃并关闭”。
- 若桌面输入偶发失去焦点，先切换到其他窗口再返回，或使用“视图 → 恢复输入焦点”（Ctrl+Shift+F6）。这个操作不会刷新页面，不会丢失草稿；不要优先重启或刷新。
- `node scripts/test-desktop.mjs` 验证安装版所用的解包运行程序。测试在独立临时目录运行，检查主要路由、确认后输入、窗口渲染，以及会议、通讯录和浏览器配置重启恢复；不覆盖安装实际用户软件。

### 原网页启动方式

1. 安装 [Node.js 22 LTS](https://nodejs.org/) 或更新版本。
2. GitHub 源码首次使用先执行 `npm ci` 和 `npm run build`；已有依赖的源码更新后重新执行 `npm run build`。
3. 在当前项目文件夹双击 `start.bat`，或运行 `npm start`。
4. 浏览器自动打开 `http://127.0.0.1:3000`。
5. 使用期间保持启动窗口开启，关闭窗口即停止系统。

启动脚本使用已构建文件，不会现场执行 `npm install`、`npm`、`npx` 或安装 Vite。支持 `C:`、`D:` 等盘符以及中文、空格目录。

系统固定使用本机地址 `127.0.0.1:3000`，不会自动切换端口，因为会议和模型设置属于该浏览器地址下的本地数据。若提示 3000 端口被占用，请先关闭旧的启动窗口或占用端口的程序，再重新启动。

## AI 模型设置

可以在“名单治理”右上角或全局“智能助手”的设置中配置：

1. 选择服务商。
2. 填写 API Key、Base URL 和模型名称。
3. 在名单页可先点击“测试连接”；全局助手会在首次生成计划时验证接口。
4. 点击“保存并使用”或“保存设置”。

各服务商分别保存。勾选“在此浏览器记住配置”时，Key 只写入当前浏览器本地存储，不写入项目文件或导出的 Excel。未配置 Key 时，格式较规范的名单仍可使用本地规则模式。

联网核验与大模型调用分离：在智能助手设置中可另行启用 Tavily 并填写搜索 Key。搜索只在用户主动要求联网、点击“AI 分析排序”或进行人员职务核验时发生，返回结果保留来源链接并标记为待人工核验。

## 会务智能助手

- 所有普通页面侧边栏和名单页顶栏都可打开同一个智能助手。
- 助手会保留当前意图和会议草稿；“新建会议”之后补充名称、相对日期、时间范围、地点和人数，不会重新询问是在新建还是修改。
- 只说“新建会议”就会立即展开可编辑表格；基本信息和会务保障项既能直接填写选择，也能继续用自然语言回填同一份草稿。即使尚未配置模型 API，表格创建方式仍可使用。
- 对话默认使用加宽侧栏；出现会议草稿或操作预览时自动展开为“左侧对话、右侧核对”工作区，顶部可手动收起或展开。小屏和收起模式通过“对话 / 核对与确认”切换，内容不丢失；核对区独立滚动，确认按钮始终保留在底部。
- 参会车辆独立登记：仅开启“停车保障”的会议显示车辆登记入口。新建会议和会议详情支持按单位填写车牌号与备注，同单位可报多辆车，无需提供人员。车辆不写入人员通讯录、不出现在正式人员名单中；可单独导出车辆 Excel。智能助手与上传会议资料可将明确给出的车辆信息填入独立车辆表格，人工确认后保存。不自动启用名单治理；停车已启用时预计车辆数不少于实际登记数。关闭停车保障隐藏入口但保留已登记车辆；旧会议人员上的临时车牌字段会迁入会议车辆登记，不推断车主或司机。
- 未提及的负责人、投屏、停车、用餐等字段使用管理中心默认值并在预览中说明，不再逐项机械追问。
- 支持创建、修改、复制、归档、恢复、移入回收站和彻底删除会议，批量更新清单任务，直接新增或修改参会人，从通讯录选人，并按后台单位/职务规则排序或导出会议名单。
- 助手创建、修改或恢复会议前会使用管理中心的会议室配置复核停用状态和时间冲突，不能绕过页面校验重复预订会议室。
- 支持通讯录新增、批量修改和删除；支持用自然语言修改并发布后台默认值、会议规则、清单模板、单位字典、排序和 Excel 输出配置。
- “打开通讯录、进入清单模板、切换模型设置”等固定站内操作不依赖模型调用；用户明确切换模块时会立即退出旧会议草稿，不会把后续要求误解成会议字段。
- 会议通知、议程、提醒文案和摘要等只读成果会直接在对话中给出；页面跳转无需确认。
- 模型只生成严格白名单操作；程序再次校验会议、任务、联系人、参会人 ID、配置版本及更新时间。普通写入、删除、配置发布和文件导出都先展示系统操作表，再由用户确认。
- 全局查询先在本机检索全部会议、任务、参会记录和通讯录，再把有界结果交给模型；结果过多时会明确标记截断，不把“最近若干条”冒充全量。
- 已确认执行的助手操作会进入“操作历史”；会议、通讯录和后台配置变更支持安全撤销，若记录在之后又被修改，系统会停止撤销以避免覆盖新内容。
- 任何写入都先显示具体变更预览，只有点击“确认执行”后才保存。
- 助手不能执行任意网址、代码、Shell 或 SQL，也不能读取或回显 API Key；联网只使用用户主动配置的搜索服务和真实来源结果。

AI 路由只允许本机回环地址访问；当前版本不作为公网 AI 代理部署。真实名单会发送给用户选择的第三方模型服务商，建议只使用公开或脱敏资料。

## OA 接入预留

已提供独立的 `/api/integrations/v1` 集成接口，可读取会议、待办、参会名单和通讯录，具备分页、令牌认证和统一错误格式；默认关闭。数据提供者与路由分离，后续可接入公司 OA 的适配器。

当前仍是本机单用户模式。企业登录、审批回调、双向写入及 OA 页面嵌入的扩展边界见 [OA 对接文档](oa-integration.md)；正式远端接入需要公司服务端部署与身份权限支持。

## 数据边界

- 管理配置：保存在 `%LOCALAPPDATA%\MeetingAssistantAI`，更换程序目录仍可复用。
- 会议、任务和参会名单：保存在 `%LOCALAPPDATA%\MeetingAssistantAI\meetings.json`，使用原子写入和备份恢复；旧版浏览器会议会在首次启动时自动迁移，浏览器存储只保留兼容缓存。
- 模型设置：保存在当前浏览器的 `127.0.0.1:3000` 本地存储。
- 助手操作历史：保存在同一浏览器本地存储，最多保留最近 30 条；只保存撤销所需的受影响记录快照。
- 人员通讯录：保存在 `%LOCALAPPDATA%\MeetingAssistantAI\contacts.json`。
- 留痕文件：只记录文件名，不复制或上传原文件。
- 管理服务读取失败时，系统会阻止新建会议和名单整理，避免静默按错误默认值运行。

当前版本定位为本机单用户工具，暂不包含多人账号权限、云端会议库、消息通知和复杂审批流。新增一种全新的业务流程类型仍需开发；日常规则、模板、字段和单位口径可直接在管理中心维护。
