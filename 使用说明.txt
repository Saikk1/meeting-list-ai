会务智办｜AI全流程会议助手（3.0.2）

桌面安装版：运行“会务智办-3.0.2-安装版.exe”，安装后从桌面快捷方式打开。
桌面便携版：直接运行“会务智办-3.0.2-便携版.exe”，放在可写入的文件夹中。
两种 EXE 都内置运行环境，无需安装 Node.js。AI 功能仍需要联网和模型额度。
EXE 未配置签名证书，不宣称已数字签名。
GitHub 下载的 Setup.exe 是安装版，Portable.exe 是便携版，内容与本地中文名称文件相同。

一、源码网页模式怎么启动
1. 电脑先安装 Node.js 22.13 或更新版本。
2. 首次下载 GitHub 源码后，在项目目录运行 npm ci，再运行 npm run build。
3. 双击 start.bat，或运行 npm start；源码更新后要重新构建。
4. 页面就绪后浏览器会自动打开 http://127.0.0.1:3000。
5. 使用期间保持黑色窗口开启，关闭窗口即停止系统。

start.bat 只运行已构建文件，不会代替安装依赖或构建。
支持 C:、D: 等盘符以及带中文、空格的文件夹。
为保证浏览器里的会议和模型设置始终属于同一地址，系统不会自动更换端口。
若提示 3000 端口被占用，请先关闭旧启动窗口或占用端口的程序再重试。

二、模块怎么分工
“会议项目”负责一场会议的全流程核对。
“名单治理”负责名单识别、单位归并、排序和 Excel 导出。
“会务待办”负责集中查看与处理不同会议的事项。
“管理中心”负责维护公司默认值、会议标准、清单模板、单位字典和导出格式。

各模块相互联动，但不会混成一个大页面。
会议不必提供正式名单，也可仅录预计人数、手动录人或从通讯录选人。
停车车辆按单位独立登记，不绑定人员；会议座次在详情中单独编排。

三、管理中心怎么用
1. 点击主导航“管理中心”。
2. 在“公司与会议规则”修改负责人、时间、人数、停车、餐标、加水间隔和风险提醒。
3. 在“清单模板”新增、复制、删除、启停或调整流程事项。
4. 在“单位名称字典”维护简称和标准全称，并选择自动合并或人工确认。
5. 在“名单与导出”调整排序、输出字段、列宽、文件名、工作表、筛选、冻结首行和 AI 补充要求。
6. 在当前编辑页就近保存，只提交本页修改；通讯录新增、修改即时生效。
7. “配置总览 / 数据维护”可保存全部草稿，也可导入、导出或回滚配置。
8. 通讯录按姓名与标准单位全称去重，不将同名不同单位的人直接合并。

会议默认值、清单和提醒只影响以后新建的会议，不会覆盖已有会议任务。
单位字典、排序和 Excel 规则从下一次名单整理或导出开始生效。

管理配置保存在：
%LOCALAPPDATA%\MeetingAssistantAI\admin-config.json

即使把新版程序解压到新文件夹，原配置仍会保留。API Key 不会写入这个文件。

四、会议项目怎么用
1. 点击“新建会议”。
2. 填写会议名称、日期、地点、负责人和预计人数。
3. 选择用餐、停车、宣传、报销、PPT、欢迎屏和会议规模。
4. 创建后，系统按当前发布的清单模板生成适用事项。
5. 每项任务可更新状态、负责人、截止日期、备注和留痕文件名。
6. “参会人员”可手动添加或从通讯录选择，也可进入名单治理整理并保存回会议。

五、名单治理怎么用
上传 Excel、Word（docx）、PDF/OCR、图片或文本，也可以直接录入或粘贴名单
→ 点击“开始智能整理”
→ 核对姓名、单位、部门和职务
→ 确认有歧义的单位合并建议
→ 预览管理中心规定的字段和排序
→ 导出 Excel，或保存回当前会议。

单次合计最多 100,000 字，单个工作表最多 5,000 行。
超出时系统会明确提示拆分，不会悄悄截断后面的人员。

六、在网页里配置大模型
1. 进入“名单治理”，或打开全局智能助手设置。
2. 点击右上角“规则模式”或“AI 已配置”。
3. 选择 DeepSeek、OpenAI、Kimi、豆包或“自定义”。
4. 填写 API Key、Base URL 和模型名称。
5. 点击“测试连接”，成功后点击“保存并使用”。

各服务商配置互相独立。Key 只保存在当前浏览器，不进入管理后台配置、历史版本或 Excel。
未填写 Key 时，系统会使用本地规则处理格式较规范的名单。

七、数据提醒
安装版 / 网页版会议、任务、名单、通讯录和管理配置保存在 %LOCALAPPDATA%\MeetingAssistantAI。
便携版数据和浏览器资料在 EXE 旁“会务智办数据”目录；迁移时一同复制。
模型设置保存在对应的浏览器资料中。
工作区切换保留未保存表格，但刷新和关闭不保存草稿，请先保存。
升级和卸载保留安装版业务数据；替换便携 EXE 时保留其数据目录。
留痕文件只记录文件名，不复制或上传原文件。
使用 AI 时，名单文字会发送给所选模型服务商。
建议使用公开或脱敏名单，不要上传身份证号等敏感信息。
